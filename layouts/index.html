At Travelers

Applied AI
Case review cut from roughly 6 hours to 30 minutes. A Python and FastAPI service, run as a nightly batch, summarizes each policy's claim notes with citations and answers the standard review questions ahead of time. It went out through shadow mode and a pilot group.
Agents
A multi-agent renewal system, now in pilot with early users. Built on the Strands SDK and Bedrock AgentCore. A nightly batch over every policy up for renewal replaced an on-demand agent, so each decision is reproducible and auditable. Agents never write to policy systems, and an underwriter approves every adverse decision.
Platform
An eval gate every prompt and model change has to pass. A golden dataset labeled by underwriter SMEs runs on every pull request, and a judge model from a different model family samples production output. The gate caught a model-upgrade regression before release. Agent tools go through an MCP gateway, with Okta for identity.

Projects

Argus
Catches 21 of 22 seeded bugs on its 32-case eval corpus. A lead agent on the Claude Agent SDK hands the diff to 6 specialist subagents, and a verifier tries to refute each finding before it posts. It runs as a GitHub Action at $0 a review, on a Claude subscription token. Code Write-up
Bosun
Turns a plain request into a spec, then into parallel builder agents across repos. It watches CI and Argus reviews and sends findings back to the builders for fix rounds. Hooks and permission rules fence agent writes, a lease lets only one supervisor act at a time, and merges, sends, and spending wait for human approval. Private repository
Stride
14,004 scheduler runs with zero errors in private beta, at two cents a turn. An SMS coach that texts first. A no-model scheduler decides when, and a Haiku router sits in front of a Sonnet agent with 21 tools. 345 tests and 97 eval checks gate every pull request. Code
Apex
Add a metric to a YAML file and the agent gains a tool at the next cold start. A Telegram health agent on Strands and Claude through Bedrock, with single-table DynamoDB. Its eval suite passed 66 of 66 runs. Code Write-up
Stock Intel
80% of its 27 commands never call the model. Telegram market intelligence on Lambda, DynamoDB, SQS, and EventBridge. 8 scheduled scanners push alerts, and it runs for about $1 to $3 a month. Code
